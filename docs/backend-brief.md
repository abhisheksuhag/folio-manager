## Fixed API contract
- GET /api/session -> `{user: User|null, csrfToken: string}`; creates an anonymous session if needed.
- POST /api/auth/demo -> `{user: User}`; creates separate demo user/session per browser; if already in demo return same user. Seed only per-user watchlists; demo market/portfolio data exclusively in server/providers/demo.ts. Root will call session again after authentication to get fresh CSRF.
- POST /api/auth/register `{name,email,password}` -> `{user}`
- POST /api/auth/login `{email,password}` -> `{user}`
- POST /api/auth/logout -> `{ok:true}`
- GET /api/workspace -> Workspace from shared/types.ts. Demo only for demo user; registered users empty except imported/live rows. Use explicit FX: demo 87.45 (2026-09-04), production configured USDINR or official provider; unavailable FX must not masquerade current; capabilities/asOf/source explicit.
- PATCH /api/preferences `{currency:'INR'|'USD',name?:string}` -> `{user}`
- GET /api/search?q= -> `{securities: Security[], indices: {id:string,name:string}[]}`; demo isolated catalog; live Alpha Vantage SYMBOL_SEARCH when configured plus user imported securities; no live mock fallback.
- GET /api/stocks/:id -> StockData (decode id); demo provided; live Alpha Vantage quote, daily history and fundamentals when configured, otherwise imported quote + empty history/fundamentals, source shown. Guard unsupported IDs.
- GET /api/indices/:id -> `{id,name,securities:Security[],source:string,asOf:string,complete:boolean}`. Demo SP500/QQQ/NIFTY50/NIFTY100/NIFTY500 catalog is a clearly marked sample, complete=false. Live allow CSV index constituents upload (below) or imported security memberships, with no fabricated full membership. Unknown index 404.
- POST /api/watchlists `{name}` -> `{watchlist: Watchlist}`
- PATCH /api/watchlists/:id `{name}` -> `{watchlist}`
- DELETE /api/watchlists/:id -> `{ok:true}`
- POST /api/watchlists/:id/items `{securityId}` -> `{watchlist}`; ensure source security exists, no duplicates.
- DELETE /api/watchlists/:id/items/:securityId -> `{watchlist}`
- POST /api/import `{csv:string,broker:'INDmoney'|'Upstox'|'Manual',kind:'holdings'|'transactions'|'history'|'constituents'}` -> `{imported:number}`; validate entire file before writing, errors with row numbers, CSV formula-safe export root handles. Holdings replaces ONLY selected broker's snapshot; native currency, explicit price/asOf. Transactions de-dup by stable content hash or provided id, never invent holdings from incomplete transaction files. Import history includes date,value,invested,netFlow,benchmark optional in INR; snapshots separate from current holding values. Constituents includes index,ticker,name,exchange,currency,country,sector; import securities safely not overwriting quote with 0. Live imports mark connection method csv. Reject portfolio imports in demo, tell user create real account; or isolate if adding support explicitly.
- GET /api/import/template?kind=holdings|transactions|history|constituents -> raw downloadable CSV. Columns documented in docs/server.md. Holdings required ticker,name,exchange,currency,country,assetClass,sector,quantity,averagePrice,price,previousClose,asOf. Defaults validate optional reasonable values; optional accountId. IDs for stocks deterministic country:exchange:ticker to avoid collisions.
- POST /api/connections/upstox/connect -> `{url:string}`; create user-bound expiring OAuth state, redirect official https://api.upstox.com/v2/login/authorization/dialog using env UPSTOX_CLIENT_ID/UPSTOX_CLIENT_SECRET/UPSTOX_REDIRECT_URI (callback endpoint below). If missing config 503 meaningful message. No secrets returned. Demo cannot connect live.
- GET /api/connections/upstox/callback -> redirect /app/settings?connected=upstox (or ?error=...). Exchange code server-side official API, encrypted persist; tokens expire daily, mark expired on 401, no unsupported refresh-token assumption. Root has verified https://upstox.com/developer/api-documentation/authentication/ and official /v2/portfolio/long-term-holdings endpoint. GET holdings normalized, classify exchange and ISIN, annotate unavailable sector etc. Preserve manual import transactions.
- POST /api/connections/:broker/sync -> `{ok:true}` (broker path 'upstox'|'indmoney'); demo no pretending live refresh. Upstox official GET holdings + positions where feasible; mutual funds if documented supported. Agent may browse primary docs. INDmoney official MCP https://www.indmoney.com/mcp now exists; root has not found endpoint yet. Implement bounded configurable MCP adapter env INDMONEY_MCP_URL/TOKEN, explicit allowed read-only tool names only. Never claim tested upstream. Discover tools schema and validate result before normalizing; fail with actionable error if unrecognized schema. No model tool writes. If endpoint is not documented, no speculative OAuth. CSV is complete fallback.
- DELETE /api/connections/:id -> `{ok:true}`; remove encrypted token and broker's holdings, preserve transactions/history and state retention explain docs.
- GET /api/analysis/messages -> `{messages: AnalysisMessage[]}`
- POST /api/analysis `{question:string,securityId?:string}` -> AnalysisResult; deterministic structured-data insights when no AI key, labeled kind=calculated with sources/as-of. Answer concentration, movement contributors, allocation, best/worst, stock valuation data. Unsupported questions explicitly say what's missing; never hallucinate news or historic valuations.
