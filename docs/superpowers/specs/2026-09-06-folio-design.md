# Folio application design

Implement the user's complete stock tracker brief in a new workspace. Use React + TypeScript + Vite for the client and Express + SQLite for a self-hosted application server. Shared typed models normalize India/US securities, currencies, holdings, transactions, snapshots and watchlists. Financial calculations consume explicit FX rates and never infer historical returns by plotting today's holdings backward.

Routes: / (public landing), /login, /register, /onboarding, /app (dashboard), /app/portfolio, /app/holdings, /app/explore, /app/markets, /app/index/:id, /app/stock/:id, /app/watchlists, /app/transactions, /app/ai, /app/settings. Authenticated demo sessions have isolated persistent watchlists and sample provider data. Registered accounts receive empty portfolios and can import statements or connect a supported provider.

Use an HTTP-only session cookie, server-side session hashes, scrypt passwords, authenticated request CSRF tokens, request rate limits, security headers, AES-GCM token encryption, ownership checks, and redacted audit logging. No order endpoints. Upstox OAuth and read-only holdings fetching use official APIs. INDmoney official MCP is integration-dependent: provide a configurable server-side adapter and honest configuration status, with validated CSV imports usable immediately. Market data uses Alpha Vantage when configured; unavailable data is visible rather than synthesized. Cached provider results retain source and observation date. Optional AI provider uses only supplied structured context and labels interpretation; deterministic portfolio insights work without a model.

Transactions and historical prices support cash/position reconstruction, dividends, deposits, withdrawals, splits, fees and taxes. TWR, volatility, drawdown, CAGR and XIRR are calculated only when the inputs support them. Benchmark comparisons normalize both series from the same date and disclose local currency versus FX-adjusted comparisons.

Visual design follows DESIGN.md. Default demo dashboard should be immediately useful and polished, while live accounts never silently fall back to sample data. All navigation, search, filters, exports, watchlists and settings must work. Verify financial edge cases and API security with automated tests; inspect desktop and mobile and exercise complete browser flows. Real broker/MCP consent and production deployment remain dependent on external credentials.
